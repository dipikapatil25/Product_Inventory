# 🚀 Mini Project

## Interactive Product Inventory & Analytics Dashboard

### 📌 Project Description

The Interactive Product Inventory & Analytics Dashboard
is a JavaScript-based console application designed to
manage product inventory and perform basic financial analysis.

The application allows users to add products, categorize
them according to price, calculate total inventory value,
filter affordable products, and generate formatted reports.

### ✨ Features

1. Add new products with their prices.
2. Store products using arrays and objects.
3. Validate user input.
4. Categorize products as Budget, Standard, or Premium.
5. Display all inventory products.
6. Calculate total inventory value.
7. Filter products priced below $200.
8. Generate formatted product reports.

### 🧠 JavaScript Concepts Used

- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrow Functions
- Arrays and Objects
- forEach()
- filter()
- map()

### 💻 Sample Input

Enter Product Name: Monitor
Enter Product Price: 150

### 📊 Expected Output

--- Initializing Inventory System ---

--- Processing Inventory Roster (forEach) ---

* Item: Laptop ($800) -> Category: Premium
* Item: Mouse ($25) -> Category: Budget
* Item: Monitor ($150) -> Category: Standard

--- Financial Analytics ---

Total Inventory Value: $975

Filtered Affordable Items (Under $200):
["Mouse","Monitor"]

Formatted Report List:
["LAPTOP: $800","MOUSE: $25","MONITOR: $150"]

## ▶️ How to Run the Project

### Step 1: Install Node.js

Download and install Node.js.

### Step 2: Open VS Code

Open the project folder in Visual Studio Code.

### Step 3: Open Terminal

Open the terminal in VS Code.

### Step 4: Run an Assignment

Navigate to the required assignment folder.

Example:

cd "Assignment 1"

Run:

node index.js

### Step 5: Run the Mini Project

Navigate to the Mini Project folder.

cd "Mini Project"

Run:

node index.js

Enter the product name and price when prompted.

Note: The Node.js versions use readline for terminal input.
